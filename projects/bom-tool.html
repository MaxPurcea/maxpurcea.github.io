Princeton Carbon Works · Summer 2026

Automating the parts-shortage review

Someone regularly checked by hand whether upcoming builds had every part they needed, and decided which contract factory should cover each gap. I built a Python and Excel tool that does that check from live bill-of-materials data.

RoleEngineering Intern
TimelineSummer 2026
ToolsPython, pandas, Excel
ImpactReplaced a recurring manual review
On this page
  1. How it works
  2. Why it mattered

How it works

  1. Read. The tool pulls live bill-of-materials data instead of a stale export.
  2. Check. It compares what upcoming builds need against what's on hand and flags every build that is short on parts.
  3. Assign. It routes each shortfall to one of the company's two contract factories.
  4. Hand off. The results land in Excel, where the team already works, so nobody has to learn anything new.

Why it mattered

This review used to be a recurring manual task. Now it is a repeatable check that takes one run. The lesson I took away is that a small script that removes a weekly chore can be one of the most valuable engineering tools a team has.

Part numbers, quantities, and supplier details are confidential and not shown.
