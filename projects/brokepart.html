BrokePart

A mobile application intended to help users identify a broken, faulty, or missing component of a tool or appliance from a photograph, and restore it to working order through repair instructions, replacement-part sourcing, or a custom 3D-printed part.

StatusDevelopment of first version
PlatformiOS and Android (Expo)
RoleProduct design and development
Started2026
On this page
  1. User flow
  2. Design decisions
  3. Next steps

User flow

  1. Input: the user submits a photograph and a short description of the problem.
  2. Diagnosis: the application identifies the system and the likely broken, faulty, or missing component.
  3. Repair: where practical, step-by-step repair instructions are provided.
  4. Sourcing: otherwise, affordable and reliable replacement parts are listed with the reasoning for each.
  5. Fabrication: where no replacement exists, the user can request a CAD model and 3D-printed part.
  6. Installation: instructions for fitting the part and returning the item to normal use.

Design decisions

  • Expo (React Native) was selected for the first version so that one codebase supports both iOS and Android.
  • The application is designed for non-specialist users, with plain-language instructions and a minimal number of steps.

Next steps

  • Complete the photograph-to-diagnosis workflow.
  • Test with real broken items and measure diagnostic accuracy.
  • Add part sourcing and a request form for custom printed parts.
